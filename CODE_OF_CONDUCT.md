# Code of Conduct

We want everyone who participates in the `cleanup-tool` community to have a positive and welcoming experience.

## Our standards

- Be respectful, kind, and constructive.
- Welcome newcomers and assume good intent.
- Give and accept feedback gracefully.
- Stay on topic and keep discussions productive.
- Do not tolerate harassment, discrimination, or abusive behavior of any kind.

## Scope

This code applies to all project spaces: GitHub issues, pull requests, discussions, and any other public communication channel.

## Reporting issues

If you experience or witness behavior that violates this code, please report it privately to the maintainer(s). You can use GitHub's private reporting features or contact the maintainer through the contact information on their GitHub profile.

All reports will be handled confidentially.

## Enforcement

Maintainers have the right and responsibility to remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this code. Continued disruptive behavior may result in a temporary or permanent ban from the project.

## Acknowledgment

This document is based on common open-source community standards and the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
