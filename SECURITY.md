# Security Policy

## Supported versions

Only the latest released version of `cleanup-tool` is actively supported with security updates. If you are running an older version, please upgrade to the latest release before reporting an issue.

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately rather than opening a public issue.

**Preferred method:** Use GitHub's private vulnerability reporting feature for this repository.

If private reporting is not available or appropriate, you can also contact the maintainer(s) privately through their GitHub profile contact information.

Please include as much of the following as possible:

- A clear description of the vulnerability.
- Steps to reproduce it, if possible.
- The affected version(s).
- Potential impact.
- Any suggested mitigation or fix.

## What to expect

- We will acknowledge receipt of your report as soon as possible.
- We will investigate and aim to provide an initial response within a reasonable timeframe.
- We will keep you informed as we work on a fix.
- We will publicly disclose the issue after a fix has been released, giving you credit if you wish.

## Scope

Security reports should focus on vulnerabilities in the `cleanup-tool` codebase, build process, or released artifacts. General bugs or feature requests should be reported as regular GitHub issues.
